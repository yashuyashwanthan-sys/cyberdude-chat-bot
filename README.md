# CyberDude Chatbot 🤖

An intelligent full-stack AI chatbot application featuring a responsive conversational interface, modular backend integration, and custom message processing.

## 🛠️ Tech Stack
- **Frontend**: React.js, CSS3, HTML5
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Language**: JavaScript (ES6+)

## ✨ Key Features
- **Conversational UI**: Clean, responsive chat interface supporting real-time interaction.
- **Modular Architecture**: Scalable backend routes separating API endpoints, database queries, and response logic.
- **Database Integration**: Chat history and user sessions stored securely in MongoDB.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB running locally or a MongoDB Atlas URI

1. **Clone the repository:**
   ```bash
